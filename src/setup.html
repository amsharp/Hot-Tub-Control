Hot Tub — widget setup

iOS can't put a web page in a widget, so use one of these. Tap Copy, no typing.

Control buttons — Apple Shortcuts

For each: Shortcuts app → + → Add Action → Get Contents of URL → paste → name it. Then add the Shortcuts widget to your Home Screen.

Status widget — Scriptable

Install Scriptable (App Store) → new script → paste → add a Scriptable widget → pick this script. Tapping it opens the full controls.
